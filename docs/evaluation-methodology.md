# Evaluation Methodology

This repository is a public demonstration of a structured computer-use evaluation workflow. It does not reproduce client tasks, proprietary rubrics, internal tooling, or confidential datasets.

## Step-level review

Each action is reviewed in context across four dimensions: consistency, action match, reasonableness, and intended effect.

## Overall review

The trajectory is separately reviewed for instruction following, tool use, task completion, and efficiency. A trajectory can complete the task while still containing a quality issue, while individually plausible actions can still fail overall if the required end state is not reached.

## Confidentiality

All examples are synthetic and independently created for this repository.
